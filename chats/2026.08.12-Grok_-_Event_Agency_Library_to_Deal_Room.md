**Collaborative workspace for event agencies: Personal structured library → Interactive deal room.**

This is a strong product concept. It bridges two pain points event agencies face daily:

1. **Scattered internal knowledge** — past proposals, vendor rates, creative concepts, budgets, floor plans, timelines, case studies, and playbooks live in folders, Notion pages, Drive, emails, and people’s heads.
2. **Fragmented client collaboration** — pitching and refining an event still happens via PDF proposals, email threads, shared drives, and Zoom calls with no single source of truth.

### Core Idea

Every team member (or the agency as a whole) maintains a **personal structured library** of reusable, tagged, versioned assets and knowledge. With one action, selected pieces of that library are assembled into a branded, permissioned **interactive deal room** shared with the client (and optionally vendors or partners). The library stays private and structured; the deal room becomes the living, collaborative face of the opportunity.

### How the Transformation Works

- **Library side (internal)**: Structured, searchable, modular. Think content blocks + metadata (event type, budget range, venue type, industry, past client, success metrics, creative style, sustainability flags, etc.). Includes templates, past decks, rate cards, risk notes, production checklists, and creative references.
- **Deal room side (external)**: Instantly generated from library selections + new custom content. Feels like a modern digital sales room (Dock-style) but purpose-built for events: interactive timelines, live budget builders, mood boards, vendor shortlists with status, approval workflows, comment threads on specific elements, and e-sign ready proposals.
- **The “turn”**: Curate → Assemble → Share. Changes in the library can optionally sync (or stay frozen) into active rooms. Rooms can be cloned or archived back into the library as new reusable patterns.

### Key Capabilities That Make It Stick for Event Agencies

- **Modular content blocks** with strong tagging and relationships (e.g., “this lighting package + this AV vendor + this timeline template” as a reusable combo).
- **Deal room components** tailored to events: interactive run-of-show, seating/floor-plan collaboration, budget scenario toggles, vendor status board, creative approval gallery, risk/assumption log, mutual action plan.
- **Permissioning & branding**: White-label rooms, client-specific views, controlled external access (clients, freelancers, venues).
- **Handover magic**: Once the deal closes, the room (or selected sections) converts cleanly into an internal project workspace or production plan.
- **Intelligence layer**: Surface best-matching library items based on RFP details, past similar wins, or client preferences. Track which content blocks actually close deals.
- **Vendor/partner layer** (optional extension): Controlled sub-rooms or invitations so preferred vendors can update availability/pricing inside the deal context.

### Differentiation vs Existing Tools

Most event tools focus on post-sale project management, registration, or onsite execution. Proposal tools (Nusii, Proposify, Eventscript, etc.) and generic sales rooms (Dock, etc.) or client portals (Planning Pod, FuseBase, SuiteDash) handle pieces of the problem. Few tightly couple a high-structure internal knowledge library with a purpose-built, interactive, multi-party deal room optimized for the complexity and visual/creative nature of event selling.
